**Benang merah**: Kuna (2023) menitrasi cuka pasar dan mendapat **5,9 %** asam asetat, padahal label menulis **5,4 %**. Dijawab di akhir: selisih itu ≈ 2 mL titran (≈ 40 tetes), jauh di atas ketidakpastian buret, jadi nyata — *asalkan* NaOH distandardisasi dengan benar.

**Rumus kunci**: `Kw = [H₃O⁺][OH⁻]`; `pH = −log[H₃O⁺]`; sebelum ekivalen (kuat–kuat) `[H₃O⁺] = (n_HCl − n_NaOH)/V_total`; asam lemah awal `[H₃O⁺] ≈ √(Ka·C)`; daerah penyangga `pH = pKa + log([A⁻]/[HA])`; di ekivalen `[OH⁻] ≈ √(Kb·C_A⁻)`, `Kb = Kw/Ka`; rentang indikator `pH ≈ pKa(HIn) ± 1`.

## 3. Fakta yang sering keliru (hindari di naskah)

**Analitik / titrasi**
1. **Titik akhir ≠ titik ekivalen.** Ekivalen = teori (stoikiometri), akhir = yang teramati (warna); selisihnya = galat titrasi.
2. **Titik ekivalen tidak selalu pH 7.** Asam lemah + basa kuat → basa (cuka ≈ 8,7); basa lemah + asam kuat → asam (NH₃–HCl ≈ 5,3 untuk 0,05 M).
3. **"Netral = pH 7" hanya pada 25 °C.** pKw turun saat suhu naik (100 °C ≈ 12,25 → netral ≈ 6,1); air panas tidak menjadi asam.
4. **Akurasi ≠ presisi.** Banyak angka desimal atau sebaran sempit tidak berarti benar.
5. **Mengulang hanya mengecilkan galat acak (∝ 1/√n)**, tidak menghilangkan galat sistematik.
6. **Simpangan baku sampel memakai n − 1.**
7. **Uji Q dipakai sekali per set data dan tidak untuk n < 3**; membuang data karena "tidak cocok" tanpa uji = tidak jujur.
8. **Indikator berubah dalam rentang ≈ 2 satuan pH (pKa ± 1)**, bukan tepat di satu pH. Fenolftalein memudar lagi pada pH sangat tinggi (> ≈ 13) — jangan bilang "semakin basa semakin merah".
9. **NaOH bukan standar primer** (higroskopis, menyerap CO₂) → selalu distandardisasi (KHP atau asam oksalat).
10. **Konsentrasi indikator berpengaruh**: terlalu banyak indikator (asam lemah juga) ikut bereaksi dengan titran.
11. **"±" untuk ketidakpastian/toleransi**, "≈" untuk perkiraan (aturan seri).
12. **Warna indikator alami bergantung ekstrak & pelarut** — sebut rentang "sekitar", jangan satu angka pasti.
13. **% (b/v) ≠ % (b/b)**: cuka 5,9 % hampir selalu g per 100 mL; tulis jelas.
14. **Beer–Lambert linear hanya untuk larutan encer & cahaya monokromatik**; absorbansi tanpa satuan dan bukan persen serapan (A = 1 → 10 % diteruskan, bukan 100 % diserap).
15. **ppm (mg/kg) ≈ mg/L hanya untuk larutan berair encer.**
16. **Elektrode kaca mengukur aktivitas H⁺, bukan konsentrasi**; kemiringan teoretis 59,16 mV/pH hanya pada 25 °C.
17. **Kesetimbangan dinamis, bukan berhenti** (reaksi maju = mundur).

**Kinetika & termodinamika (untuk seri 2–3)**
18. Orde reaksi **tidak** dibaca dari koefisien stoikiometri kecuali untuk tahap elementer.
19. **Katalis tidak menggeser kesetimbangan** dan tidak mengubah ΔH/ΔG; hanya menurunkan Eₐ untuk dua arah.
20. **ΔG < 0 ≠ cepat** (intan → grafit spontan tapi sangat lambat); spontan ≠ seketika.
21. **Eksotermik ≠ spontan** (es mencair endotermik tapi spontan di atas 0 °C).
22. Aturan "naik 10 °C = laju 2×" hanya kira-kira untuk Eₐ ≈ 50 kJ/mol di sekitar suhu kamar.
23. **Potensial reduksi standar E° intensif** — tidak dikali koefisien reaksi.
24. Entropi bukan "kekacauan kamar"; definisi statistik S = k ln W.
25. Zat antara ≠ keadaan transisi (antara = lembah, bisa diisolasi; keadaan transisi = puncak).
